The World Today — a one-page newspaper front page summing up Tuesday 24 November 2026: NATO sends an AWACS early-warning aircraft to Poland after three Russian missiles land on NATO soil, plus the chess title duel in Geneva, a warship sunk off Libya, the Indonesia factory fire, and the rest of the day in a ticker. Drawn entirely in pure-stdlib Python 3.13 (no image libraries): a 5x7 bitmap font, vector shapes and a hand-rolled PNG encoder render the 1024x1024 front page deterministically.

## Run it
